# Stealth Escape – AI-Assisted 2D Game Project

A 2D top-down stealth-puzzle game created using **GDevelop** and AI-assisted workflows. This project demonstrates how modern AI tools can be integrated with game engine mechanics to rapidly prototype, design, and build a functional game.

---

## 🎮 Gameplay & Mechanics

- **Stealth System:** Avoid enemy detection line-of-sight using a dedicated `SNEAK` mechanic.
- **Key & Door Logic:** Explore the level, collect keys, and unlock doors to escape.
- **Dynamic Lighting:** Flashlight mechanic for navigation and visual atmosphere.
- **Failure & Success States:** Clear "Caught" and "Escaped" screens with instant restart capabilities.

---

## 🛠️ Built With

- **Engine:** [GDevelop](https://gdevelop.io/) (Open-source, event-driven game engine)
- **AI Integration:** AI generation for core asset concepts, logic structured workflows, and visual elements.
- **Version Control:** Git & GitHub

---

## 💡 Technical Highlights

- **Event-Driven Architecture:** Implemented collision detection, UI state switching, and inventory counters using GDevelop's condition-action event system.
- **AI-Driven Prototyping:** Used AI tools to accelerate asset generation and game loop design, cutting down development time significantly.

## 🚀 How to Run / Play

1. Clone or download this repository.
2. Open **GDevelop**.
3. Select **Open a project** and point to the `game.json` file in this directory.
4. Click **Preview** to play the game directly in GDevelop.
